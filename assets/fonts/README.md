# Tipografía institucional

El proyecto utiliza exclusivamente dos familias para texto nuevo y renderizado:

- **Gelasio**: títulos, encabezados, cifras editoriales y citas.
- **Inter**: cuerpo, navegación, controles, tablas y texto técnico.

Los archivos fuente originales se conservan en sus carpetas respectivas junto con su licencia SIL Open Font License. Las versiones WOFF2 optimizadas que consume el sitio están en `frontend-mirror/templates/beez3/webfont/`.

Los nombres tipográficos históricos del espejo se mantienen únicamente como aliases de compatibilidad en `typography.css`; esos aliases cargan Gelasio o Inter y nunca los binarios anteriores.
