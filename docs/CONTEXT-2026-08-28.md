## SEO y Replit: aprendizaje permanente

1. `https://www.vonwobeser.com` está publicado y es el dominio canónico institucional actual.
   Un canonical no afecta la carga de la página, pero evita dividir indexación entre el dominio
   oficial y las URLs técnicas de Replit.
2. La resolución de URL base acepta, por orden, `SITE_URL`, `PUBLIC_SITE_URL`, la configuración
   `site_url` administrable y el valor institucional. **No** usa `REPLIT_DOMAINS`: Replit expone
   también dominios efímeros tipo `*.replit.dev` durante Preview y pruebas.
3. Canonical, alternates, Open Graph, JSON-LD, sitemap, `robots.txt` y `llms.txt` consumen la
   misma base institucional. `robots.txt` es público y cacheable.
4. Los enlaces internos ya no apuntan a `/index.html`, `/index.php/index.html` ni
   `/index.php/home/`. Las redirecciones 301 se conservan para enlaces externos históricos, pero
   los menús y pie enlazan directo a la portada canónica.
5. El reporte SEO de Replit debe ejecutarse sobre
   `https://webpage-von-wobeser-2026.replit.app/` y con la ventana en primer plano. No usar rutas
   antiguas que redirigen, pues el auditor las marcará como advertencia de carga.
6. Los avisos de Vite para `templates/beez3/css/typography.css` y fuentes de `beez3` son recursos
   heredados resueltos al runtime; el build correcto es la evidencia relevante.

## Sincronización actual de Replit

El historial reciente de `main` fue enmendado, por lo que una copia de Replit anterior no debe
hacer `git pull --rebase`. En el workspace instalado, con autorización del operador, usar:

```sh
git stash push -u -m "replit-local-before-a6c2408" && git fetch origin main && git reset --hard origin/main && npm run db:migrate && CONFIRM_PARTNER_ORDER_RECONCILIATION=1 npm run team:reconcile-partner-order && npm run check && npm run test:security && npm run test:performance && npm run build
```

El comando ya fue ejecutado con éxito contra `a6c2408`. Para futuras actualizaciones que no
reemplacen un commit publicado, regresar al flujo normal de `git pull --rebase origin main` después
de revisar el estado local.
