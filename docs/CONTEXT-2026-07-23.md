## Seguridad implementada

- Sesión administrativa mediante cookie `HttpOnly`, `Secure`, `SameSite=Strict`; no se guardan
  Bearer tokens en `localStorage`.
- PostgreSQL guarda solamente hashes de sesión, actividad, expiración, estado MFA y protección
  CSRF.
- Contraseñas nuevas con Argon2id; los hashes bcrypt heredados se migran después de un login
  correcto.
- Política de contraseñas nuevas: 12–16 caracteres. Las claves generadas por el panel tienen
  16 caracteres, son definitivas y se muestran una sola vez.
- Ya no se obliga a cambiar la contraseña durante el primer acceso.
- MFA TOTP obligatorio para `super_admin` y `admin`, con secreto cifrado mediante AES-256-GCM y
  códigos de recuperación de un solo uso.
- Recuperación manual mediante `npm run admin:recover -- --confirm=<correo>`, leyendo
  `ADMIN_EMAIL`, `ADMIN_BOOTSTRAP_PASSWORD` y `MFA_ENCRYPTION_KEY` desde Replit Secrets. El
  comando no imprime contraseña ni hash.
- `/api/admin/init` permanece retirado.
- Rate limiting compartido, validación Zod, consultas parametrizadas con Drizzle, sanitización
  XSS, protección SSRF, validación real de archivos, CV privados y WebSocket autenticado.
- CI incluye TypeScript, build, pruebas de seguridad, Gitleaks, Semgrep y CodeQL.

## Operación en Replit

Flujo seguro cuando Replit y GitHub no pueden avanzar por fast-forward:

```bash
git fetch origin main
git merge --no-ff origin/main -m "Sync Replit with GitHub main"
git push origin main
npm run check && npm run test:security && npm run build
```

Después se ejecuta Republish. `kill 1` se reserva para reiniciar el proceso del workspace; un
republish ya reinicia el despliegue.
