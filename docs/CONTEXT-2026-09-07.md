## Talento: CV y solicitudes

Los dos formularios de Talento (`/bolsa-de-trabajo` y `/bolsa-de-trabajo/pasantes`) comparten el
endpoint propio `POST /api/career-applications`, con `multipart/form-data`. La corrección cubre el
input real de archivo —no un botón visual— y remueve los tokens/handlers ocultos heredados de
Joomla que el endpoint estricto podía rechazar.

- La migración `20260902_0001_career_applications.sql` creó de forma aditiva e idempotente el
  almacenamiento de solicitudes y su registro de procesado. No depender de scripts no
  versionados para crear tablas en Replit.
- Los CV se conservan como documentos privados en App Storage. Administración permite
  descargarlos sólo con permisos de solicitudes y descarga privada; no existe URL pública.
- Si App Storage no está disponible, el servidor responde con error explícito y no simula éxito.
  Diagnósticos seguros: `CV_STORAGE_UNAVAILABLE` y `CAREER_APPLICATIONS_SCHEMA_PENDING`.
- En autoscaling de Replit, ClamAV puede existir sin firmas inicializadas. La configuración actual
  permite `CLAMAV_REQUIRED=false` para no bloquear todos los CV por esa condición. Si Sistemas
  instala firmas verificadas, puede volverlo obligatorio sin cambiar código.
- Las reglas móviles de los dos formularios fuerzan una sola columna y límites de ancho para que
  campos, botón, aviso y enlace no se salgan del viewport.

## Leadinfo: preparado, no activo

La integración directa de Leadinfo quedó preparada sin Site ID y está inactiva por defecto. En ese
estado no carga script, no crea cookies, no envía visitas y no cambia GA4.

- La tarjeta administrativa valida sólo un Site ID alfanumérico con `_` o `-`; no acepta URLs,
  HTML ni scripts pegados.
- Para activarse exige Site ID válido, interruptor activo, confirmación de revisión legal y un
  entorno público HTTPS autorizado.
- Tiene una categoría de consentimiento independiente: **Identificación de empresas** / **Business
  visitor identification**. Sólo tras aceptarla se carga una vez el script oficial; revocar el
  consentimiento detiene el rastreo y limpia sus cookies.
- No se ejecuta en Administración, vistas previas, localhost ni entornos no autorizados. CSP sólo
  permite los orígenes concretos de Leadinfo, sin `unsafe-inline` ni permisos amplios.
- No enviar a Leadinfo nombres, correos, CV, mensajes ni datos de formularios. No usar Google Tag
  Manager ni pegar snippets en el CMS.
