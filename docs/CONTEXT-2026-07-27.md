## Cargas seguras y reconocimientos

El fallo de los logos no estaba relacionado con que el disco externo del usuario estuviera
desconectado. La causa fue arquitectónica:

1. El navegador sí enviaba el archivo.
2. PostgreSQL guardaba únicamente la ruta.
3. El archivo quedaba en `/uploads` dentro del filesystem efímero del despliegue.
4. Un Republish podía crear una instancia sin esos bytes y las rutas quedaban rotas.

La corrección:

- Los raster se validan por firma y contenido decodificable, no solo por extensión/MIME.
- Sharp sanitiza PNG/JPEG/WebP y conserva transparencia cuando corresponde.
- Se generan nombres físicos aleatorios y derivados optimizados.
- En producción/Replit, imágenes, videos y documentos se escriben en Replit App Storage antes de
  guardar la referencia administrativa.
- La biblioteca consulta los medios persistentes y evita ofrecer referencias cuyos bytes ya no
  existen.
- Se recuperaron nueve logos de reconocimientos 2025/2026 como WebP válidos y livianos.
- La migración idempotente `npm run media:migrate-storage` protegió ocho archivos existentes en
  App Storage durante la ejecución confirmada del 27 de julio.
- El bucket se identifica mediante `REPLIT_APP_STORAGE_BUCKET_ID`; su valor vive en el entorno y
  no se documenta.
- PostgreSQL continúa guardando rutas y metadatos, no blobs.

Commits principales: `94204aa` (`Fix secure recognition image uploads`) y `aff1dd1`
(`Persist uploaded media and restore recognition logos`).

## Operación segura en Replit

Cuando Replit y GitHub han divergido por commits de Publishing:

```bash
git fetch origin
git checkout main
git merge --no-ff origin/main -m "Sync Replit with GitHub main"
npm ci
npm run check
npm run test:security
npm run build
git push origin main
```

Después se usa Republish. `kill 1` reinicia el proceso del workspace; no reemplaza el Republish
de producción.

Para migrar cargas heredadas al almacenamiento persistente:

```bash
test -n "$REPLIT_APP_STORAGE_BUCKET_ID" && echo "Bucket ID: OK" || echo "Bucket ID: FALTA"
npm run media:migrate-storage
```

El comando debe reportar solo conteos, nunca valores de Secrets.
